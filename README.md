# Idea: Leveraging Cryptocurrency Mining Infrastructure to Enhance AI

**Author:** Igi (Ignacy)  
**Date:** May 2, 2025

## What is this project about?

This document contains an original idea proposed by Igi, which suggests using the computational power of cryptocurrency mining hardware (GPUs, ASICs) to support the training and operation of artificial intelligence models (like ChatGPT).

## What is the concept?

- Instead of using mining hardware purely for cryptocurrencies, it could be re-purposed to process AI tasks.
- OpenAI (or another company) could create a dedicated currency (e.g., ChatGPT Coin), where participants contribute compute power and earn tokens.
- A decentralized network would enhance AI’s performance and resilience.
